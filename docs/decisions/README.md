# Architecture Decision Records

Lightweight ADRs for decisions that constrain future work. Create one only for architectural
choices (structure, contracts, cross-feature behavior) — never for ordinary implementation details.

Format: `NNNN-short-title.md` with Context / Decision / Alternatives considered / Consequences / Status.
Status is one of `proposed`, `accepted`, `superseded`. A superseded record stays in place with a
pointer to its replacement.
